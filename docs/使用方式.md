1) 克隆本仓库 `twilight-princess-chs`

2) 自行准备：游戏数据（消息库与两套字库归档）、`assets` 里的 icon/banner（用于 mod 显示）、译文表、两套字体文件

- `fonts.fontres`：游戏里画对话正文、菜单、栏位文字的那套字库
- `fonts.rubyres`：游戏里画存档界面、地图菜单楼层与地名、Game Over、对比度页面的那套字库

译文表的格式：

```csv
key,<原文列>,<译文列>,comment
zel_00/1,原文,译文,备注
zel_unit/0/one,原文,译文,备注
```

- 一行 = 一格文本；打包只读译文列，`comment` 随便写
- 表头四列固定顺序；中间两列的名字由 `scripts/config.json` 里该语言的 `draft_col` / `locale_col` 定
- `key` = `<资源>/<单元>[/<格名>]`：资源 = 归档内 BMG 名去掉 `.bmg`；单元 = 消息号（同一消息号重复出现时，后一条补 `#<下标>`）；格名只出现在多格资源上（`zel_unit` 的 `one` / `other`，用于表达单位的单复数形式）
- 文本字面：换行写 `\n`，其它控制码写 `\xNN`，标签写 `<Tggcccc>`，带数据的标签写 `<Tggcccc:hex>`
- 文件编码 UTF-8

3) 翻译

翻译 `input/texts.<L>.csv` 的译文列（换行写 `\n`，标签原样 `<Tggcccc>`）

4) 打包

```
python scripts\build_bmg.py --lang <L>
python scripts\build_bfn.py --lang <L>
Copy-Item work\<L>\scratch_parts\*.arc work\<L>\sjis_parts\ -Force
python scripts\verify_texts.py --lang <L>
python scripts\diag_pack.py --lang <L>
python scripts\build_sjis_pack.py --lang <L> --check
python scripts\build_sjis_pack.py --lang <L>
```

产物：`dist\<id>.dusk`

5) 装包

把 `dist\<id>.dusk` 拷进 dusklight 的 mod 目录（exe 同级的 `mods\`），默认就会启用。

同一批资源只放一个包：换地区或换变体时，先把上一个包从 `mods\` 删掉。
