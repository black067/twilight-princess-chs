# 译文约定（cn 段：美版英文原文 -> 简体中文）

## 输出格式

- 每批输出一个 CSV：表头 `id,cn`，行数与输入同序同量，`id` 原样回抄。
- 只写 CSV 行，不要 markdown 代码块、不要额外说明、不要引号包裹整行。
- 文件编码 UTF-8。CSV 里含逗号的字段按标准 CSV 加双引号。

## 文本字面（照抄英文侧的写法）

- 标签 `<Tggcccc>` 与 `<Tggcccc:hex>` 必须原样保留：数量、内容、在句中的位置都不许改（标签是换色/图标/数据占位，不是文本）。
- 换行写成 `\n`（反斜杠 + n），数量与位置跟英文一致，不要新增或删除换行。
- 原文为空或只有空白的格子：`cn` 照原样留空/留空白，不要填字。

## 长度

- 输入表第 3 列 `max` = 该格每行允许的最大字符数（按官中同格算出的保守值，不含标签）。
- 译文每行（不含标签、不含 `\n`）字符数不得超过 `max`；`max` 为空时只要求行数与英文一致。
- 偏短的译文优于超长：宁可用并列词代替整句，也不要撑破 `max`。

## 用词

- 名词一律查 `docs/本地化规则/glossary.cn.csv`（英文词 -> 中文）。表里有的必须用表里的译名。
- 表里没有的专有名词：按表里同类词的风格音译/意译，并把它写进本批的 terms 文件。
- 不参考官方中文本的任何句子；只看名词表。
- 标点用全角（，。！？「」……——），原文用全角数字/字母的地方保持全角。
- 按键、缩写（A、B、Z、Wii、TV 等）保留拉丁字母与半角数字。
- 语气词与口癖（Brudda、gor、Meow、Eee 等）译成中文口语腔，保留角色个性；不要照抄英文拟声。
- 商店/菜单类短句用简洁名词短语（如 `Set` -> 设定、`Buy` -> 购买、`Quit` -> 退出）。

## 语境提示

- 说话人标签 `<Tggcccc>` 是语音占位，不要删；英文里的称呼（如 `Brother` 指鼓隆族的战友）按上下文译。
- 同一批里的短句常常是同一菜单的项，用词要互相对齐（如 `Yes`/`No` 固定「是」/「否」）。
