黄昏公主汉化 MOD Ver.{tag}

安装：把 `yiga_cn_eu.dusk` 放进 `dusklight` 的 `mods` 目录，在 Mods 窗口里启用。**记得先删掉旧版的包。**

选语言：

- 打开 Mods 窗口，选中本 mod
- 上方的 `Translation` 选择译文：
  - 简体中文: `Simplified Chinese`
  - 繁体中文: `Traditional Chinese`
  - 简体中文 (机翻): `Simplified Chinese (DeepSeek)`
- 在 `Game language` 一栏勾上**游戏设置里用的那个语言**（默认勾的是法语）
  - 欧版一般是 `French` / `German` / `Spanish` / `Italian` / `English (EU disc)`
  - 美版是 `English (US disc)`
  - Wii 美版 rev2 还可能是 `French` / `Spanish`
  - 日版是 `Japanese`


切换语言后重启 `dusklight` 确保正常生效

另外：

- 以 `orig_` 为前缀的包，字体更加**原汁原味**。

注意：

- 主要测试环境是欧版 + 法语；其它版本欢迎 issue 反馈（附语言设置截图最佳）
