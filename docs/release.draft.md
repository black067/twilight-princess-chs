黄昏公主汉化 MOD Ver.{tag}

根据你的光盘版本选择：
- 欧版: 选 `yiga_zh_hans_eu.dusk`, 语言选 `French`
- 美版: 选 `yiga_zh_hans_us.dusk`
- 日版: 选 `yiga_zh_hans_jp.dusk`

另外：
- 以 `orig_` 为前缀的包，字体更加**原汁原味**，可根据个人喜好选用

安装方式：下载和你的光盘配套的版本，放进 `dusklight` 的 `mods` 目录，然后通过 `dusklight` 的 Mods 界面启用（一般来说会自动启用）
- 提示：记得覆盖或者先删除旧版的汉化包

注意：
1. 只用欧版测试过，如果你的光盘不是欧版，欢迎 issue 反馈给我（如果能附上你的语言设置等截图最佳）
2. 如果想启用/关闭 mod，需要重启 Dusklight 才会生效（因为 mod 会替换字库）
