# 发布指南（官方 mod 站）

`dist/<id>.dusk` 可以直接上传到 [twilitrealm.dev](https://twilitrealm.dev/mods/)——这份 mod 目录同时也是游戏内
Mod 浏览器的数据源。

## 上传前：跑本地闸门

**先跑 `python scripts/build_sjis_pack.py --check`**（只校验元数据、不写包）。闸门在 `build_sjis_pack.py` 的
`check_meta()`，阈值按站点实测取的保守值：

- `id`：小写字母/数字/下划线、单点分隔（同客户端 `utils::is_valid_mod_id`）；**发布后不可改**（catalog 主键）。
- `name` ≤ 48 字符、`description` ≤ 200 字符，且**必须单行**。
- `version` 形如 `X.Y.Z`；更新时递增（客户端按 `id` + `version` 校验包与条目一致）。
- `description` **不许带链接**——站点把它当 mod 页摘要，链接填站点的 Source 字段。

`mod.json` 只写 `MOD_FIELDS` 白名单里的字段（`id/name/version/author/description/icon/banner`）；
`config` 段里多出来的键会被丢弃并在控制台提示，不会进包。

## 站点侧还要手工填

- 分类（Utility / UI）、License、Source URL（GitHub 仓库地址）、截图、changelog。
- 长文（安装说明、致谢、AI 声明）放页面的描述正文里，不要塞进 `mod.json`。

## 站点校验的实测边界

- mod 页摘要 = `mod.json` 的 `description`（catalog API 逐字符比对确认）。
- 已收录 mod 的 description 最长 265 字符，且全部单行、无链接。
- `icon` / `banner` 非必需：缺图时列表显示首字母占位。
- 上传上限 5 GB；纯数据包（`containsNativeCode=false`）在 iOS 的 Mod 浏览器里也可见。

## 两个变体与版本

- 两个变体各传各的（id 不同、互不覆盖）：`dist/yiga_zh_hans.dusk`（开源字体）与 `dist/yiga_zh_hans_ique.dusk`（官方字库）。
- 发新版：改 `config.example.json` 里的 `version` 后重新打包上传；**id 不能变**（改了等于换一个 mod）。
