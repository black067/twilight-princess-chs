# 发布规则（TwilitRealm mod 站）

`dist/<id>.dusk` 可以直接上传到 [twilitrealm.dev](https://twilitrealm.dev/mods/)——这份 mod 目录同时也是游戏内
Mod 浏览器的数据源。

## 上传前：跑本地闸门

**先跑 `python scripts/build_sjis_pack.py --check`**（只校验元数据 + 图片，不写包）。闸门在
`build_sjis_pack.py` 的 `check_meta()`：

- `id`：**硬限制**，按客户端 `utils::is_valid_mod_id`——小写字母/数字/下划线/点，首尾不能是点、
  不能有连续点（单段也合法，但不含点会提示改用反向域名）；**发布后不可改**（catalog 主键）。
- `description`：**硬限制 ≤ 265 字符**（站点已收录 summary 的最大值）；带换行或链接只提示——
  站点把 `description` 当 mod 页摘要，已收录的摘要全是单行、无链接，链接填站点的 Source 字段。
- `name` ≤ 48 字符；`version` 形如 `X.Y.Z`，更新时递增（客户端按 `id` + `version` 校验包与条目一致）。

## mod.json 的格式

以客户端 `src/dusk/mods/loader/manifest.cpp`（读 `mod.json` 的唯一实现）与 `docs/modding.md` 为准，
本项目的实际长相：

```json
{
  "id": "yiga.zh.hans",
  "name": "Chinese (Simplified) Translation",
  "version": "1.0.0",
  "author": "Yiga Clan",
  "description": "...",
  "icon": "res/icon.png",
  "banner": "res/banner.png"
}
```

- **只有 `id` 必填**（客户端会校验，非法直接整个 mod 加载失败）。`name`/`version`/`author` 的缺省分别是
  包文件名 / `?` / `unknown`，`description` 缺省为空；多出来的字段被忽略。
- 字节格式：2 空格缩进、键序 `id→name→version→author→description→icon→banner`、**末尾不留换行**、
  UTF-8 无 BOM。
- `icon`/`banner` 是**包内路径**；客户端找不到时自动回退 `res/icon.png`、`res/banner.png`。
- `config` 里这两项填**本地 PNG 路径**，打包时固定放进包内 `res/icon.png`、`res/banner.png`；
  `icon` 要 1:1，`banner` 约 3.5:1、宽 ≥ 800（dusklight `docs/modding.md` 的建议）。不配就不写这两个
  字段，站点列表显示首字母占位。
- 站点从**包里**取图（catalog API 返回的图尺寸就是包内文件的尺寸），后台不用另传图。
- `config` 段里多出来的键会被丢弃并在控制台提示，不会进包。

## 站点侧还要手工填

- 分类（Utility / UI）、License、Source URL（GitHub 仓库地址）、截图、changelog。
- 长文（安装说明、致谢、AI 声明）放页面的描述正文里，不要塞进 `mod.json`（摘要硬限制 265 字符）。
  现成的长描述草稿见文末。

## 站点校验的实测边界

- mod 页摘要 = `mod.json` 的 `description`（catalog API 逐字符比对确认）。
- 已收录 mod 的 description 最长 265 字符，且全部单行、无链接。
- `icon` / `banner` 非必需：缺图时列表显示首字母占位。
- 上传上限 5 GB；纯数据包（`containsNativeCode=false`）在 iOS 的 Mod 浏览器里也可见。

## 包与版本

- 一个 lang 段在一个地区出一份 `dist/<转义 id>.dusk`；中文段（`langs.zh-Hans`）是对外发布的
  `dist/yiga_zh_hans_<region>.dusk`（`<region>` = us / eu / jp），共 3 个包，各传各的（id 不同、互不覆盖）。
- 换语言 = 换 `--lang`：id / name / description 都写在该 lang 段的 `mod` 里，包名跟着 id 走
  （`escape_mod_id`：`.` → `_`），所以多语言的包能共存在 `dist/` 里。
- 另有一个保留原字库位图的变体（`--variant origin`，走就地改写路线，见[管线复现](管线复现.md)），仅限研究使用。
- 发新版：改该 lang 段里的 `version` 后重新打包上传；**id 不能变**（改了等于换一个 mod）。
